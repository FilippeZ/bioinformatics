# 🧬 BioPipeline App — End-to-End Computational Drug Discovery Platform

This is the web application component of the **BioPipeline** bioinformatics platform.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
